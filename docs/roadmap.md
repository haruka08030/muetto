# 開発ロードマップ

---

## フェーズ構成

| Phase | 名称 | 内容 | 完了条件 |
|---|---|---|---|
| 0 | 基盤 | 既存コード削除、Flutter プロジェクト雛形、Supabase 初期化、認証、CI | サインインしてホーム（空）が表示される |
| 1 | 香水 DB と検索 | スキーマ、初期データ投入、テキスト検索、香水詳細 | 香水を検索して詳細を閲覧できる |
| 2 | ログとコレクション | 試香ログ CRUD、写真、オフライン下書き、マイコレクション、ウィッシュリスト | 店頭で試香ログを記録できる（オフライン含む） |
| 3 | 好み分析 | 集計バッチ、ダッシュボード、ドリルダウン、レコメンド | 10 件ログを入れると好み傾向が表示される |
| 4 | OCR 検索 | カメラ、オンデバイス OCR、候補マッチング | ボトル撮影から香水を特定できる |
| 5 | 導線と投稿 | 購入導線、クリック計測、ユーザー投稿・修正提案 | 外部サイトへ遷移でき、新規香水を登録できる |
| — | リリース準備 | ストア申請素材、プライバシーポリシー、審査対応 | App Store / Google Play 公開 |

## Phase 0: 基盤

- [ ] 既存コード（Chrome 拡張・Notion 連携 Edge Function）の削除 ✅ 完了
- [ ] 要件定義ドキュメントの整備 ✅ 完了
- [ ] Flutter プロジェクト作成（`app/`）、Melos または単一パッケージ構成の決定

## リリース後（v2 以降の候補）

優先順位は v1 の実データを見てから決める。

- コミュニティ機能（他ユーザーの評価閲覧、レビュー、フォロー）
- 協調フィルタリングによるレコメンド（ユーザー数が十分になってから）
- 試香ログの時間経過記録（トップ／ミドル／ラストの段階別メモ、リマインダー通知）
- 専用の管理画面 UI
- 有料プラン
- 多言語 UI 展開
- VLM による画像認識フォールバック
