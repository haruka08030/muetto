## 2. タブ構成（ボトムナビゲーション）

```
┌────────┬────────┬──────────┬────────┬────────┐
│  ホーム │  検索  │ ＋ログ    │ コレク  │  分析  │
│  S-04  │  S-05  │  S-08    │ ション  │  S-13  │
│        │        │ (中央FAB) │  S-10  │        │
└────────┴────────┴──────────┴────────┴────────┘
```

**中央の FAB を「ログを書く」に割り当てる。**
最頻出のユースケース（店頭での試香記録）を最短距離に置くため。

---

## 3. 最重要導線 — 店頭での試香記録

目標: **アプリ起動から保存完了まで 30 秒以内、電波が悪くても完了できる。**

```
アプリ起動
   │
   ├─ [中央FAB] ログを書く
   │      │
   │      ▼
   │   香水を選ぶ
   │      ├─ カメラで撮る (S-06) ─→ 候補カード ─┐
   │      ├─ テキスト検索 (S-05) ──────────────┤
   │      └─ 最近見た香水から選ぶ ─────────────┤
   │                                            ▼
   │                                     ログ入力 (S-08)
   │                                            │
   │                          ┌─────────────────┤
   │                          │ 星タップ（1回で保存可能な状態に）
   │                          │ ＋ メモ・写真・コンテキストは任意
   │                          ▼
   │                        保存
   │                          │
   │                   オンライン？
   │                    ├─ Yes → 即同期
   │                    └─ No  → ローカル下書き保存 → 復帰時に自動同期
   ▼
完了トースト（「あと N 件で分析が始まります」を併記）
```

**設計上の要点**

- 星をタップした瞬間に保存可能な状態にする。メモも写真も必須にしない
- 検索できなかった場合でも、**製品名を自由入力してログだけ先に残せる**逃げ道を用意し、
  後から香水マスタに紐付けられるようにする（店頭で行き止まりを作らない）
- オフラインであることをユーザーに意識させない。同期状態は控えめに表示する

## 4. 購入導線

```
香水詳細 (S-07) / レコメンド (S-15)
   │
   ├─ [少量から試す]  → サブスクサービス（カラリア等）
   └─ [現品を買う]    → 公式ショップ / 楽天 / Amazon
          │
          ▼
   click_events に記録 → 外部ブラウザで開く
```

用途に応じて 2 つの導線を明確に分ける。
「気になるが確信がない」段階ではサブスク、「確信がある」段階では現品、という
ユーザーの心理状態に対応させる。

---

## 5. 分析の説明責任

好み分析の数値は、**必ず根拠へ辿れること**。

```
ダッシュボード (S-13)
   │  「ベルガモット — 好き（8件のログに基づく）」
   ▼  タップ
ドリルダウン (S-14)
   │  その 8 件のログ一覧と、それぞれの評価
   ▼  タップ
香水詳細 (S-07)
```

レコメンドカードも同様に、推薦理由の香料名から
「なぜそれが好きと判定されたのか」へ辿れるようにする。

## 6. UI 方針

- **落ち着いた配色**。香水という題材に合わせ、彩度を抑えたニュートラルなベースに、
  香調カテゴリごとのアクセントカラーを割り当てる（ウッディ＝褐色系、シトラス＝黄緑系 など）
- 香調カテゴリの色は分析グラフ・香水詳細・検索フィルタで**一貫させる**。
  ユーザーが色でカテゴリを覚えられるようにする
- ノートピラミッドはタップで展開するアニメーションを持たせる（Flutter の強みを活かす箇所）
- ダークモード対応
- 動的フォントサイズ対応、コントラスト比 WCAG AA
